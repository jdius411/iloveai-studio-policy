Privacy Policy — ILOVEAI Studio Publishing Pipeline

Last updated: 2026-10-06

ILOVEAI Studio ("we") operates an internal tool that uses the YouTube API Services to publish and manage videos on YouTube channels that we own. This tool is not offered to the public and is not used by any third party.

By using this tool you are agreeing to be bound by the YouTube Terms of Service (https://www.youtube.com/t/terms).

Google Privacy Policy: https://policies.google.com/privacy

1. What data we access

Through OAuth 2.0, and only for channels owned by ILOVEAI Studio, the tool accesses:

  • the channel's own videos and their metadata (title, description, tags, privacy status, scheduled publish time, thumbnails);
  • playlists and playlist items on those channels;
  • comment threads on our own videos, so we can post and pin our own creator comment and read comments that viewers leave;
  • channel and video statistics and YouTube Analytics reports for our own channels.

We do not access the private data of other YouTube users.

2. How we use the data

We use the data only to:

  • upload and schedule our own videos;
  • set metadata and thumbnails;
  • manage playlists;
  • post creator comments;
  • check for duplicate uploads;
  • measure the performance of our own content.

We do not sell, rent or share this data with anyone.

3. Comments from viewers

We read public comments on our own videos so that a human staff member can reply. Replies are never posted automatically. Commenter names and comment text are kept only in local working files, and those files are deleted within 30 days.

4. Storage and security

  • OAuth tokens and API data are stored only on the studio's own computer. They are not uploaded to any third-party server.
  • Access to that computer is limited to studio staff.
  • API credentials are kept in environment variables and local credential files. They are never published.

5. Retention and deletion

  • Analytics snapshots are kept for at most 12 months.
  • Comment data is kept for at most 30 days.
  • You can revoke this tool's access at any time at https://security.google.com/settings/security/permissions. When access is revoked, the stored tokens stop working, and we delete them within 7 days.

6. Cookies

The tool is a local program. It does not set cookies on any user's device.
