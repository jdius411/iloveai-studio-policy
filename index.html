ILOVEAI Studio Publishing Pipeline

ILOVEAI Studio is a small Korean-language story studio. We make original narrated story videos for senior viewers. We publish them only on YouTube channels that we own.

The ILOVEAI Studio Publishing Pipeline is our internal tool. It uses the YouTube YouTube API Services (YouTube Data API v3 and YouTube Analytics API) to do the following on our own channels:

  • upload and schedule our own videos
  • set thumbnails
  • add videos to playlists
  • post our own creator comment
  • check for duplicate uploads
  • read our own channel statistics

The tool is not offered to the public, and it does not access other users' data.
